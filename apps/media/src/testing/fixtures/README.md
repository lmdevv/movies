# Test fixtures

Small binary files the tests use as they are; everything else is generated by `fixture-library.ts`.

- `vobsub.mkv` (3.6 KB): one DVD (VobSub, `dvd_subtitle`) subtitle track on a 720x576 canvas and
  no other stream; two subtitles, "Burned in from VobSub." at 0–3 s and "Second picture subtitle."
  at 4–6.5 s. ffmpeg cannot encode bitmap subtitles from text, so it was made with spumux
  (dvdauthor), whose font (`DejaVuSans.ttf`) must be in `~/.spumux/`:

  ```sh
  ffmpeg -f lavfi -i color=c=black:s=720x576:r=25 -t 8 -target pal-dvd -an base.mpg
  spumux -s0 sp.xml < base.mpg > subs.mpg   # sp.xml: <subpictures format="PAL"><stream><textsub
                                            # filename="t.srt" font="DejaVuSans.ttf" fontsize="28.0"
                                            # movie-width="720" movie-height="576" .../></stream></subpictures>
  ffmpeg -i subs.mpg -map 0:s:0 -c:s copy vobsub.mkv
  ```
